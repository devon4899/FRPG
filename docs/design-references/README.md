# RPGFit visual direction references

These are direction boards, not production assets. Rebuild selected marks and
glyphs as native vectors before shipping.

## Product direction

- Use Ladder/Hevy for workout structure and reachable actions.
- Use Endel for restraint, immersive canvas, and ambient motion.
- Use The Room/Elden Ring for mature material language: ink, worn stone,
  restrained brass, and engraved detail.
- Use Blackbox for sparse, confident feedback through color, motion, and
  haptics.

## Interaction principles

- Give each screen one dominant next action.
- Put actions beside the object they affect; keep the main workout action
  reachable at the bottom.
- Prefer progressive disclosure to walls of equal-weight cards.
- Make RPG identity come from progression, naming, atmosphere, and tactile
  feedback—not cartoon mascots or ornamental frames.
- Use serif type ceremonially; use highly legible sans-serif and tabular
  numerals for training data.
